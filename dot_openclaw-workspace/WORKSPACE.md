# Workspace Structure

## Root
- `IDENTITY.md` — кто я (Кими)
- `USER.md` — кто Глеб
- `SOUL.md` — принципы поведения
- `PROJECTS.md` — структура проектов и чатов
- `TOOLS.md` — инструменты, токены, инфра
- `HEARTBEAT.md` — периодические задачи
- `AGENTS.md` — конфиг агентов (приоритеты, модели)
- `README.md` — входная точка для новых сессий

## Дерево проектов

```
~/workspace/
├── core/                    # Сердце системы
│   ├── config/             # Конфиги ботов, токены
│   ├── agents/             # Определения агентов
│   ├── prompts/            # Базовые промты
│   └── logs/               # Логи, метрики
│
├── metroLog/               # Основной проект
│   ├── raw-ideas/          # Сырые идеи (вход)
│   ├── dev-core/           # Архитектура, ядро
│   ├── dev-frontend/       # UI/UX
│   ├── dev-backend/        # API, БД
│   ├── testing/            # QA, баги
│   ├── deploy/             # CI/CD
│   └── docs/               # Документация
│
├── learning/               # Обучение
│   ├── notes/              # Конспекты
│   ├── questions/          # Вопросы, разбор
│   ├── resources/          # Ссылки, материалы
│   └── exercises/          # Практика, код
│
└── inbox/                  # Входящие
    ├── dump/               # Всё подряд
    ├── quick/              # Быстрые задачи
    └── archive/            # Обработанное
```

## Принципы организации

1. **Всё начинается в inbox** — идея, задача, ссылка — сначала туда
2. **Классификация — позже** — не думай куда положить, просто брось
3. **Агенты обрабатывают** — core агент разбирает inbox, раскидывает по проектам
4. **Контекст в чатах** — каждый чат = контекст для специализированного агента

## Flow данных

```
Телеграм → inbox/dump → core агент → классификация → проект/чат
                                              ↓
                                    специализированный агент
                                              ↓
                                    результат/промт/задача
```

## Агенты

| Агент | Где живёт | Задача |
|-------|-----------|--------|
| **core** | core/admin | Настройка, оркестрация |
| **classifier** | core/agents | Разбор inbox, маршрутизация |
| **metroLog-dev** | metroLog/dev-* | Разработка, код |
| **metroLog-qa** | metroLog/testing | Тесты, баги |
| **learner** | learning/notes | Обучение, конспекты |
| **monitor** | core/monitoring | Метрики, алерты |

## Файлы в чатах

Каждый чат = директория с файлами:
- `chat.md` — история сообщений
- `context.md` — текущий контекст, промт
- `tasks.md` — задачи, туду
- `output/` — результаты, артефакты
