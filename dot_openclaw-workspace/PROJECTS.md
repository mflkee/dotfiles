# Проекты

## metroLog
- **Описание:** Основной проект
- **Чаты:**
  - `raw-ideas` — сырые идеи (голос, текст, фото)
  - `dev-core` — разработка, архитектура
  - `dev-frontend` — UI/UX, верстка
  - `dev-backend` — API, БД, инфра
  - `testing` — тесты, баги, QA
  - `deploy` — деплой, CI/CD, мониторинг

## learning
- **Описание:** Обучение и развитие
- **Чаты:**
  - `notes` — заметки, конспекты
  - `questions` — вопросы, разбор
  - `resources` — ссылки, книги, курсы

## core
- **Описание:** Сердце системы, настройка, оркестрация
- **Чаты:**
  - `admin` — настройка ботов, токены, доступы
  - `monitoring` — метрики, расход токенов, алерты
  - `backlog` — задачи на будущее, техдолг

## inbox
- **Описание:** Входящие, неразобранное
- **Чаты:**
  - `dump` — всё подряд, потом разберём
  - `quick` — быстрые задачи, 5-минутные
