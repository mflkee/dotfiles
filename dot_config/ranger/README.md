# Ranger: короткий гайд

Конфиг настроен как замена графическому файловому менеджеру: быстрый просмотр
справа, открытие обычных типов файлов через твой стек и vim-подобная навигация.

## Ежедневные клавиши

- `rr`, `fm`, `files` в zsh: открыть ranger и после выхода перейти в последнюю
  выбранную директорию.
- `j/k` или стрелки: движение вверх/вниз.
- `h/l` или Enter: назад/открыть.
- `gh`: home, `gD`: Downloads, `gc`: config, `gC`: dotfiles, `gp`: projects.
- `zh` или Ctrl-h: показать/скрыть скрытые файлы.
- `Space`: отметить файл, `v`: отметить все.
- `yy`: копировать, `dd`: вырезать, `pp`: вставить.
- `cw`: переименовать, `a`: дописать к имени, `A`: редактировать имя целиком.
- `DD`, `dD`, Delete: переместить в корзину.
- `dX`: удалить без корзины.
- `e`: открыть в Neovim.
- `x`: открыть через desktop-приложение по умолчанию.
- `X`: выбрать программу открытия вручную.
- `/`: поиск в текущей папке, `n`/`N`: следующее/предыдущее совпадение.
- `zi`: включить/выключить графические image previews.
- `zp`: включить/выключить preview pane.
- `?`: встроенная справка ranger.

## Предпросмотр

- Текст/код: `bat`, иначе обычный текст.
- Изображения: `chafa`, если установлен; иначе цветной fallback через
  ImageMagick, который уже есть в системе.
- PDF: первая страница через `pdftoppm` плюс image preview; fallback в текст
  через `pdftotext`.
- Видео: thumbnail через `ffmpegthumbnailer`.
- Архивы: список содержимого через `atool`, `bsdtar` или `7z`.

Для более качественных preview можно поставить:

```sh
paru -S --needed chafa python-pillow trash-cli mediainfo perl-image-exiftool
```
