# Перевахтовка СИКН-1520

Ветка сдачи смены. Основной файл:

`22_Разное/Подсказки/Эксплуатация/ПЕРЕВАХТОВКА.odt`

Это не акт и не отчёт — короткие тезисы для следующего инженера.

## Стиль

- Новый блок в конце документа: **дата + автор**, затем нумерованные пункты.
- Писать кратко, по делу, в том же стиле, что и предыдущие записи.
- Не переписывать старые блоки; только добавлять новый.
- В заголовке блока указывать вахту: `Макеев Г.Б. (вахта 19.11.2026 — 19.01.2027)`.
  Даты вахты уточнять по ротации/графику; в ноябре 2026 принято
  `19.11.2026 — 19.01.2027` (перевахтовка 19.09 → 19.11, шаг 2 месяца).
- Тезисы: что сделано / не сделано, состояние, где находится.
- Писать только факты: что сделано, что не сделано, в каком состоянии.
  Не давать указаний «что делать / что не делать» и не добавлять пояснения,
  если пользователь не просил. Нужен совет — пользователь скажет.
- **Не дублировать акты ТО.** Они уже отражены в актах. В перевахтовке —
  поверки, калибровки, выполненные работы, состояние оборудования.
- Замену дисков на АРМ писать тезисно: АРМ-1/АРМ-2, SAS 1.8 ТБ,
  RAID 1 восстановлен. Без пояснений про акты.

## Как править ODT

- LibreOffice + UNO, профиль `/tmp/opencode/lo_profile`, сокет 2002.
- Открыть `ПЕРЕВАХТОВКА.odt` (`Hidden=True`), курсор в конец текста,
  вставлять абзацы через `PARAGRAPH_BREAK`.
- Стиль абзаца — `Обычный`, шрифт Calibri 11, без жирного.
- Сохранять `storeToURL(..., FilterName="writer8")`.
- После сохранения проверить текст через `content.xml` или открыть ODT.
- Старые записи не удалять и не переставлять.
