# СИКН-1520

Рабочая папка: `~/SIKN1520`. Два направления:

1. **Акты ТО** — читать `akty.md` рядом с этим файлом.
2. **Перевахтовка** — читать `perevakhtovka.md` рядом с этим файлом.

## Общие правила

- Источник истины по виду ТО — график ТО и месячная Excel-книга, не старый
  шаблон. Вид ТО не подменять: если по графику ТО-3, значит ТО-3.
- Один акт на группу оборудования, как в Excel. Сигнализаторы — один акт на
  все 12 (9 ЭЛЕМЕР-СВ-11 + 3 Rosemount 2100).
- В актах ТО **не писать «Содержание работ»**: после оборудования — строка
  «Работы выполнены согласно технологической карте №…», вывод, подписи.
- В комплект класть только запрошенное: акты ТО, акт отступления, акт проверки
  ИБП. Журналы, вкладыши в формуляр, чек-листы и отчёты — только по просьбе.
- Позиции и зав. № не выдумывать и не обрезать: брать полный список из
  месячной книги/БД; если нужен поднабор — уточнить.
- Дата — фактическая в каждом акте.
- Подписанты при смене вахты: Макеев Г.Б. (МКАИР), Теплицкий А.А.
  (Саханефть), Кудренко А.П. (начальник ПСП), Евдокимов Б.Н.
  (Транснефть-Восток).
